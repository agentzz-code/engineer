# Pocket Ledger

A private, installable income-and-expense tracker. Your transactions stay only in this browser on this device.

## Put it on your home screen

1. Publish this folder with GitHub Pages (or any HTTPS web host).
2. Open the published link on your phone.
3. In the browser menu choose **Add to Home Screen** (iPhone) or **Install app** (Android/Chrome).

## Publish with GitHub Pages

Create an empty GitHub repository, upload the contents of this folder to it, then open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub will show the site address after it deploys.

The app works offline after its first visit. It stores entries in the browser, so clearing browser data or changing devices removes the local history.
